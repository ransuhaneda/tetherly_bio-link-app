# Allow one editing tab per browser profile

The MVP coordinates creator-workspace tabs within the same browser profile so only one tab can mutate the draft at a time. A user-scoped `localStorage` lease provides ownership discovery and expiry, while `BroadcastChannel` sends immediate ownership and takeover messages. Secondary and displaced tabs show a dismissible ownership modal, remain inspectable in read-only mode with a persistent takeover banner, and preserve visible unsaved input locally while disabling submission. The only actions are **Take Over Here** and **Continue Read Only** because browsers cannot reliably focus another tab. The active tab renews its lease, releases it when leaving the workspace or signing out but not when merely hidden, and a lease expires about 15 seconds after heartbeats stop. This is browser coordination, not cross-device locking, and the MVP deliberately adds no server-side stale-revision safety net or legacy-browser fallback.
